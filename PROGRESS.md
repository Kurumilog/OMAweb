         │                                          │ (с установкой)
         │                                          ▼
         │                                 [Выбор даты (DateTimeDrawer)]
         │                                          │
         ▼                                          ▼
[Корзина (CartPage)] ────────────────────────► [Оформление (MasterApplicationPage: 1-5)]
         │                                          │
         │                                          ▼
[ОМА Мастер (MasterLandingPage)] ────────────► [Кабинет заказа (OrderCabinetPage: 1-6)]
         │                                          │ (приёмка + отзыв)
         ▼                                          ▼

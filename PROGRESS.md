# PROGRESS.md — «ОМА Дом»: статус и план (обновлено 2026-10-27 19:05)

React 19 + Vite + TypeScript + Tailwind v4 (`@tailwindcss/vite`). Dev-сервер: `npm run dev` (порт 3000). Данные каталога: `src/data/*.json`. Память: Supermemory v5 (`supermemory` 5.0.3) через серверный proxy в `vite.config.ts` + `server/supermemory.ts`.

## Сделано (по файлам)
1. **Header (`src/components/Header.tsx`)** — логотип, город, поиск, «ОМА Мастер», профиль с бонусами, избранное, корзина. Клик по профилю открывает простую карточку профиля.
2. **SidebarCatalog (`src/components/SidebarCatalog.tsx`)** — чистый вертикальный каталог категорий; дублирующая кнопка «ОМА Мастер» убрана (ссылка уже есть в шапке и в мобильной навигации).
3. **CatalogSection (`src/components/CatalogSection.tsx`)** — чистая сетка товаров, локальный поиск по названию/бренду/категории, блок установки «от X руб.» на странице категории.
4. **ProductPage (`src/components/ProductPage.tsx`)** — отдельная страница товара, «Обычно берут вместе», «Установить» → «в корзину с установкой» или «оформить вызов мастера».
5. **CartContext / CartDrawer / FloatingCartButton** — корзина в localStorage, `replaceProductInCart`, бонусы 5%/3%, плавающая кнопка и вызов мастера по товарам с установкой.
6. **MasterPage (`src/components/MasterPage.tsx`)** — отточенный 9-шаговый флоу:
   - Шаг 1 (Заявка): фото, категория, адрес, окно времени, комментарий и прикреплённые товары из корзины;
   - Шаг 2 (Ориентир цены): смета по прейскуранту, бонусы, автоматический поиск мастера системой (как в Яндекс);
   - Шаг 3 (Чат с мастером): мастер назначается автоматически системой ОМА (Дмитрий К., 4.9 ★, 1.2 км от адреса), чат с уточнением деталей, заменой позиций и добавлением расходников;
   - Шаг 4 (Согласование): двусторонняя фиксация сметы и сроков;
   - Шаг 5 (Оплата): Safe Deal с холдированием средств до приёмки;
   - Шаг 6 (Логистика): «Доставка ОМА» или «Самовывоз мастером» (вариант из машины мастера исключён);
   - Шаг 7 (Выезд): интерактивные статусы («В пути» → «На месте» → ввод 4-значного ПИН-кода `1234` → «Работы начаты»);
   - Шаг 8 (Приёмка): фотоконтроль «до» и «после», автоприёмка через 24 часа;
   - Шаг 9 (Завершение): начисление бонусов, оценка мастера (1–5 звёзд), гарантия 12 месяцев.
   - Быстрый переключатель шагов 1–9 для жюри хакатона.
7. **App (`src/App.tsx`)** — виды `catalog | product | master`, подключены `ProductPage`, `MasterPage`, `FloatingCartButton`, `ProfilePanel`, `MobileBottomNav`; `ProductDetailModal` удалён. Профиль в шапке и в мобильной навигации открывает карточку профиля.
8. **ProfilePanel (`src/components/ProfilePanel.tsx`, новый)** — простая карточка: имя, телефон, город, карта лояльности, уровень и бонусы. Без вкладок и упоминаний памяти.

## Память Supermemory
- **`omaweb_project`** — только знания о проекте: `progress_md`, `homepage_md`, `context_md` и логи агентных сессий из `sessions/*.md` (`taskType: superrag`). Каталог товаров в Supermemory **не заливается** — по решению пользователя.
- **`user_{id}`** — персональный namespace на пользователя: профиль, заказы и чат (`taskType: memory`, `dreaming: instant`).
- Серверный proxy: `server/supermemory.ts`, маршруты `/api/supermemory/{status,search,add,profile,list}`; ключ читается из `.env` и не попадает в клиентский бандл.
- Синхронизация: `python3 scripts/sync_supermemory.py` (инкрементальная, `--force` для перезаписи проектных документов).
- SDK: `supermemory@5.0.3`; старый hardcoded API key из скрипта удалён.
- Профиль синхронизируется только при изменении имени, города, телефона, карты или уровня; бонусный баланс остаётся локальным и не перезаписывает память.

3. Опционально: подключить LLM к чату мастера и использовать `searchUserMemory` как контекст перед ответом.
4. Обновить `PROGRESS.md`/лог сессии после финального демо.

## Ключевые решения пользователя
- «Установить»: ориентир «от X» + выбор «в корзину с установкой» или «вызов мастера сразу».
- Flow «ОМА Мастер» — один интерактивный экран с быстрым переключателем шагов.
- Главная = только чистый каталог; в `MasterPage` убраны вводный hero-блок и блок готовых сценариев (`HeroTaskEntry` / `WhyOmaDom`) — экран сразу начинается с переключателя 10 шагов.
- В Supermemory хранить только контекст проекта и прошлые агентные сессии; товары не заливать.
- Профиль — простая карточка в нейтральной гамме (чёрный/белый/серый + синий акцент), без «Памяти ОМА» и без «Паспорта дома».

## Память Supermemory
- **`omaweb_project`** — только знания о проекте: `progress_md`, `homepage_md`, `context_md` и логи агентных сессий из `sessions/*.md` (`taskType: superrag`). Каталог товаров в Supermemory **не заливается** — по решению пользователя.
- **`user_{id}`** — персональный namespace на пользователя: профиль, заказы и чат (`taskType: memory`, `dreaming: instant`).
- Серверный proxy: `server/supermemory.ts`, маршруты `/api/supermemory/{status,search,add,profile,list}`; ключ читается из `.env` и не попадает в клиентский бандл.
- Синхронизация: `python3 scripts/sync_supermemory.py` (инкрементальная, `--force` для перезаписи проектных документов).
- SDK: `supermemory@5.0.3`; старый hardcoded API key из скрипта удалён.
- Профиль синхронизируется только при изменении имени, города, телефона, карты или уровня; бонусный баланс остаётся локальным и не перезаписывает память.

## Ключевые решения пользователя
- «Установить»: ориентир «от X» + выбор «в корзину с установкой» или «вызов мастера сразу».
- Flow «ОМА Мастер» — один интерактивный экран с быстрым переключателем шагов.
- Главная = только чистый каталог; в `MasterPage` убраны вводный hero-блок и блок готовых сценариев (`HeroTaskEntry` / `WhyOmaDom`) — экран сразу начинается с переключателя 10 шагов.
- В Supermemory хранить только контекст проекта и прошлые агентные сессии; товары не заливать.
- Профиль — простая карточка в нейтральной гамме (чёрный/белый/серый + синий акцент), без «Памяти ОМА» и без «Паспорта дома».

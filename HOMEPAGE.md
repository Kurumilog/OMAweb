# Структура и функции главной страницы OMA.by

Документ описывает структуру, кнопки, навигацию и встроенные функции официального сайта гипермаркета **ОМА** ([oma.by](https://www.oma.by)), а также их проекцию в концепцию демо-сервиса **«ОМА Дом»**.

---

## 1. Общая архитектура главной страницы

Официальный сайт OMA.by построен по модели классического омниканального DIY-ритейлера с трехуровневой шапкой, каталожным мега-меню, акционными промо-блоками и адаптивной мобильной навигацией:

```
┌────────────────────────────────────────────────────────────────────────┐
│ Header Top: Город (Минск) | Магазины | Доставка | Оплата | B2B | Инфо │
├────────────────────────────────────────────────────────────────────────┤
│ Header Middle: [ Лого ОМА ] [ Весь каталог ] [ Поиск ] [ЛК] [❤️] [🛒]   │
├────────────────────────────────────────────────────────────────────────┤
│ Header Nav: 🔥 ВСЕ АКЦИИ | Супер цены | Ликвидация | Рассрочка | Топ   │
├────────────────────────────────────────────────────────────────────────┤
│ Hero-баннер: Актуальные спецпредложения и сезонные промо-акции         │
├────────────────────────────────────────────────────────────────────────┤
│ Каталожная сетка: Популярные категории и товары дня                    │
├────────────────────────────────────────────────────────────────────────┤
│ Footer: Покупателям | О компании | Мобильное приложение | Соцсети     │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Копия основных кнопок и элементов управления

### 2.1 Верхняя сервисная панель (`header-top`)

| Кнопка / Элемент | URL / Селектор | Тип действия | Описание |
|---|---|---|---|
| **Ваш регион: Минск** | `#city` (`.js_find_city`) | Модальное окно | Выбор филиала сети и привязка остатков складов/магазинов к региону покупателя. |
| **Адреса магазинов** | `/about/departments/` | Ссылка | Интерактивная карта и список розничных гипермаркетов ОМА по всей Беларуси с графиком работы. |
| **Покупателям** | `/buyers/services/` | Выпадающее меню | Доставка, способы оплаты, самовывоз, сервис-центры, гарантия и возврат, подарочные карты. |
| **Мастера** | `/buyers/services/masters/` | Ссылка | Публичный каталог услуг проверенных специалистов (установка сантехники, дверей, кухонь). |
| **Программа лояльности** | `/buyers/discount/balans/` | Ссылка | Информация о накопительных картах «Баланс» и «Выбираем сами». |
| **B2B / Для юрлиц** | `/b2b/` | Внешний переход | Раздел для оптовых клиентов, строительных организаций и тендерных закупок. |

### 2.4 Мобильная навигация (Mobile Bottom Bar)

Для мобильной версии сайта и PWA-приложения зафиксирована нижняя панель быстрого доступа:

1. **Главная** (`/`) — иконка домика (`home`).
2. **Каталог** (`/catalog/`) — иконка сетки (`grid`), быстрый доступ ко всем категориям.
3. **Мастера** (`/masters/`) — иконка гаечного ключа (`tool`), заказ специалистов на замер и установку.
4. **Корзина** (`/cart/`) — иконка тележки (`shopping-cart`) с бейджем количества товаров и услуг.
5. **Профиль** (`/account/`) — иконка пользователя (`user`) с балансом бонусов.

## 3. Встроенные функции и интерактивные сценарии (Built-in Functions)

### 3.1 Геолокация и мультирегиональность
- **Функция:** Определение города пользователя (по IP или кукам) с возможностью ручного переключения (Минск, Брест, Гродно, Гомель, Витебск, Могилев и райцентры).
- **Влияние на каталог:** Фильтрация остатков на складах конкретного региона и расчёт сроков самовывоза/доставки.

### 3.2 Умная строка поиска с предиктивными подсказками
- **Поведение:** При вводе от 2 символов открывается выпадающий блок с:
  - 5 самыми релевантными товарами с миниатюрой, ценой и статусом наличия;
  - подходящими категориями каталога;
  - ссылкой на все результаты поиска по запросу.

### 3.3 Каталожное мега-меню (Mega-Dropdown)
- **Структура:** Двухуровневое дерево категорий:
  - 1-й уровень: Сантехника, Инструмент, Интерьер и отделка, Электрика, Стройматериалы, Крепеж и др.
  - 2-й уровень: Детализированные группы (напр. *Сантехника → Смесители и душевые системы / Унитазы и биде / Ванны*).
  - Промо-баннер внутри меню: сезонный товар или акция для текущего раздела.

### 3.4 Всплывающая корзина (Mini-Cart Popover)
- При наведении или добавлении товара показывает превью: фото, наименование, количество, сумму и кнопку быстрого перехода в чекаут.

### 3.5 Программа лояльности «Баланс»
- Расчет начисления бонусов (обычно 5% с покупки) и показ доступного количества бонусов прямо в карточке товара (`+N бонусов`).
- Поддержка оплаты бонусами до 20–30% стоимости покупки.

## 4. Трансформация главной страницы в концепт «ОМА Дом»

В проекте «ОМА Дом» привычная главная страница гипермаркета дополняется **входом по задаче**:

1. **Сохранение привычной айдентики:**
   - Фирменные цвета ОМА (голубой `--oma-blue: #00A3E8`, нейтральный светлый фон, скругления карточек).
   - Все стандартные кнопки шапки (Каталог, Поиск, Корзина, Личный кабинет, Выбор города) сохранены на своих местах.
2. **Инновация первого экрана:**
   - Вместо традиционного баннера акций первым блоком выводится вопрос: **«Что хотите сделать?»**
   - Строка ввода задачи с поддержкой свободного ввода (например, *"заменить смеситель на кухне"* или *"покрасить комнату"*).
   - 6 интерактивных карточек готовых жизненных сценариев с прозрачной стоимостью «под ключ» (товар + расходники + установка мастером + бонусы).
3. **Связка товаров и услуг:**
   - На карточках товаров с монтажом появляется кнопка **«Установить»** с фиксированной ценой и гарантией 12 месяцев.

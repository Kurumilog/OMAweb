# Инструкция по установке и запуску проекта «ОМА Дом»

Проект разработан для хакатона ОМА — цифровой экосистемы товаров для дома и сертифицированных услуг «ОМА Мастер».

---

## 🚀 Быстрый старт (Quickstart)

### 1. Системные требования
* **Node.js**: версии `>= 18.0.0` (рекомендуется LTS 20+)
* **npm**: версии `>= 9.0.0`
* **ОС**: macOS, Linux или Windows

### 2. Клонирование и установка зависимостей
```bash
# Клонируйте репозиторий
git clone https://github.com/Kurumilog/OMAweb.git

# Перейдите в папку проекта
cd OMAweb

# Установите зависимости
npm install
```

### 3. Переменные окружения (.env)
Файл `.env` уже включён в репозиторий со всеми необходимыми ключами для корректного запуска:
```env

```
Дополнительная ручная настройка `.env` не требуется.

### 4. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска проект откроется по адресу:
👉 **[http://localhost:3000](http://localhost:3000)** (или `http://localhost:3001`, если порт 3000 занят).

## 🛠 Доступные npm-скрипты

| Команда | Описание |
| :--- | :--- |
| `npm run dev` | Запуск сервера разработки с Hot Module Replacement (Vite) |
| `npm run build` | Проверка типов TypeScript (`tsc`) и сборка production-бандла в директорию `dist/` |
| `npm run preview` | Локальный запуск production-сборки из директории `dist/` |

## 🌟 Ключевые сценарии для демонстрации

1. **Товар + Установка («под ключ»)**:
   * Откройте любой товар (например, смеситель или унитаз).
   * Выберите переключатель «С установкой» — в чек автоматически добавляется проверенный мастер и сопутствующие расходники.
2. **Доставка мастером (бесплатно)**:
   * При заказе товара с установкой в корзине доступен отдельный тариф доставки: «Доставка мастером (бесплатно)» — мастер сам привозит купленный товар к моменту монтажа.
3. **ОМА Мастер (Чат и согласование)**:
   * Вызов мастера с фиксацией цен по фото и этапами «Было / Результат».
4. **Программа лояльности 2.0 (`/?view=loyalty`)**:
   * Разделение денежного кэшбэка (4% с покупок в рублях) и баллов активности за выполнение заданий месяца.
   * Визуальная лесенка наград: **3 балла** (прокат инструмента -30%), **6 баллов** (доставка -30% или материалы -5%), **10 баллов** (максимальные скидки).
